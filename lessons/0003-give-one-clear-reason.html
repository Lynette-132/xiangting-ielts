观点后面，跟一个真正的理由

今天的胜利：用 because 把“我怎么想”和“为什么”连成一个完整、清楚的句子。

注意：自动保存不等于已经提交。网页答案只保存在这台 iPad；哥哥看不到，直到你复制反馈卡并粘贴到聊天。

为什么接着练这个

你已经能把连续意思切成完整句。下一步不是堆高级词，而是在清楚句界的基础上，让一个观点得到一个直接理由。这同时服务于写作的“任务回应”和“连贯与衔接”。

1. 间隔复习：先切句（2 分钟）

不看第2课，把下面内容切成两个完整句。只改标点和大小写。

I study English every day it gives me more choices

写完再核对

I study English every day. It gives me more choices.

2. 今天只用一个结构（3 分钟）

观点 + because + 原因

I want to improve my English because it gives me more choices.

观点：I want to improve my English
原因：it gives me more choices

当 because 放在句子中间连接直接理由时，前面通常不加逗号：

正确 I study online because it is convenient.

今天不写 I study online, because it is convenient.

3. 认出“理由”（3 分钟）

哪个后半句真正回答了“为什么想通过考试”？先在心里选择，再展开答案。

  1. I want to pass the exam because it is an exam.
  2. I want to pass the exam because I want to return to school.
查看答案

第 2 句。它提供了具体动机；第 1 句只是重复题目，没有解释原因。

4. 你来写（6 分钟）

任选下面一个开头，用 because 写一个完整句。理由必须回答“为什么”，不追求高级词。

  • I want a stable job ...
  • I study English every day ...
  • I want to return to school ...

5. 20 秒自检与交作业

  1. because 前面是一个观点吗？
  2. because 后面真的回答“为什么”了吗？
  3. because 前有没有多余的逗号？
  4. 整句结尾有没有英文句号？

把反馈卡发给哥哥。哥哥只反馈“理由是否成立”和句子边界，然后请你立即重写一次。
