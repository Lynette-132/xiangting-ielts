理由后面，再放一个看得见的例子

今天的胜利：在“观点＋理由”后，用 For example 补一个具体例子。

注意：自动保存不等于已经提交。网页答案只保存在这台 iPad；哥哥看不到，直到你复制反馈卡并粘贴到聊天。

你已经会用 because 回答“为什么”。这一课只向前走一步：让读者看见这个理由在现实中是什么样子。

1. 间隔复习：先找理由（2 分钟）

不看第3课，补全一句“观点＋具体理由”。

I study English every day because ...

写完再看示例

I study English every day because it gives me more choices.

2. 今天只加一个结构（3 分钟）

观点 + because + 理由. For example, + 具体例子.

I study English every day because it gives me more choices. For example, I can apply for jobs that require English.

理由是一般解释；例子是一个具体的人、行动或情境。For example 后面加英文逗号，例句本身要完整。

3. 哪一句真的是例子？（3 分钟）

先在心里选择，再展开答案。

  1. For example, English is important.
  2. For example, I can read job advertisements written in English.
查看答案

第 2 句。它给出了一个具体行动；第 1 句只是换一种方式重复观点。

4. 你来补一个例子（7 分钟）

保留下面前两句，再补一个具体例子。只写三句，不追求高级词。

I want a stable job because a regular income makes me feel secure. For example, ...

5. 20 秒自检与交作业

  1. because 后面是否回答了“为什么”？
  2. For example 后面是否出现了具体行动或情境？
  3. 三句是否都用英文标点，并以大写字母开头？

发给哥哥后，哥哥只检查“例子是否具体”和句子边界，再请你立即重写一次。
